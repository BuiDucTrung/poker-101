# Poker Dealer Trainer

Web luyện dealer Texas Hold'em: từ 2 lá của dealer + 5 lá chung, chọn 2 lá bỏ đi để giữ 5 lá mạnh nhất.
Next.js (JavaScript), không backend — xuất web tĩnh.

## Chạy trên máy
```
npm install
npm run dev     # mở http://localhost:3000
```

## Đẩy lên GitHub
```
git remote add origin https://github.com/<tên-bạn>/poker-dealer-trainer.git
git push -u origin main
```

## Deploy lên Vercel
Vào vercel.com → Add New → Project → chọn repo này → Deploy (Vercel tự nhận Next.js, không cần cấu hình).
